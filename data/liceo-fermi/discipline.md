# Liceo Fermi — Discipline

Raggruppamento delle materie affini. La colonna **Classe di concorso** è **nostra
mappatura** (serve al SaaS sostituzioni), non un campo osservato in EDT — vedi
[docs/edt/discipline.md](../../docs/edt/discipline.md).

| Codice | Nome | Classe di concorso |
|---|---|---|
| LET | Lettere | A011 / A013 |
| STF | Storia e Filosofia | A019 |
| LIN | Lingue straniere | AB24 |
| MAF | Matematica e Fisica | A027 |
| SCN | Scienze | A050 |
| ART | Discipline artistiche | A017 |
| MOT | Scienze motorie | A048 |
| REL | Religione | IRC |

⚠️ `MOT` è sia codice materia sia codice disciplina: in EDT non è un problema
(tabelle distinte). Dettagli in [docs/edt/discipline.md](../../docs/edt/discipline.md).
